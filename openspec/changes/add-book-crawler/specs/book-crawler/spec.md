## Purpose

此能力負責從國家圖書館開放資料與 Google Books API 取得書籍資料（含分類與封面圖片），以 ISBN 比對合併同一本書的資料，並依書籍分類方式呈現，作為後續書籍查詢與瀏覽功能的資料基礎。

## ADDED Requirements

### Requirement: 支援已核准之書籍資料來源
系統 SHALL 支援從以下資料來源取得書籍資料：國家圖書館（NCL）開放資料（月度新書資訊）、Google 圖書（Google Books API）。系統 SHALL NOT 從未經法遵評估核准之來源（例如博客來、讀冊、誠品線上）取得資料，除非該來源已改為提供官方合法存取管道並重新完成法遵評估。

#### Scenario: 從已核准的來源取得資料
- **WHEN** 系統對其中一個已核准的資料來源進行資料存取
- **THEN** 系統應能取得該來源提供的書籍資料

#### Scenario: 嘗試存取未核准的來源
- **WHEN** 有人嘗試將系統設定為從未核准的來源（如博客來、讀冊、誠品線上）取得資料
- **THEN** 系統 MUST 拒絕該設定，直到該來源提供官方合法存取管道並重新完成法遵評估為止

### Requirement: 依書籍分類呈現資料
系統 SHALL 將抓取到的書籍資料依書籍分類進行整理與呈現。各資料來源之分類體系得各自保留（不強制統一為單一分類體系）。

#### Scenario: 依分類瀏覽書籍
- **WHEN** 使用者依照某個書籍分類查詢資料
- **THEN** 系統呈現屬於該分類的書籍清單，並標示該分類所屬的來源

### Requirement: 遵守來源網站之法律與使用規範
系統於存取任一來源資料時，SHALL 遵守該來源之服務條款（Terms of Service）、robots.txt 規範及相關法律規定。當某種存取方式可能違反前述規定時，系統 MUST 排除該存取方式或該來源，不得為求資料涵蓋率而違反規定。此為所有資料來源存取方式的最高前提，優先於效率與涵蓋率考量。

#### Scenario: 來源明確禁止自動化存取或重製內容
- **WHEN** 某資料來源的服務條款、robots.txt 或內容信號明確禁止自動化存取或未經同意重製其內容
- **THEN** 系統不得對該來源執行爬取，並排除該來源或改採其官方提供之合法存取方式

#### Scenario: 來源提供官方開放資料或 API
- **WHEN** 資料來源提供官方開放資料或 API（如國家圖書館開放資料、Google Books API）
- **THEN** 系統應優先透過官方開放資料或 API 存取，而非以未經授權之網頁爬取方式取得資料

### Requirement: 書籍資料含封面圖片
系統 SHALL 取得並呈現每筆書籍資料對應的封面圖片。若某來源之資料不含封面圖片，系統得改由其他已核准來源補足。

#### Scenario: 來源提供封面圖片
- **WHEN** 資料來源之書籍資料包含封面圖片
- **THEN** 系統呈現該書籍時 SHALL 一併呈現封面圖片

#### Scenario: 來源未提供封面圖片
- **WHEN** 資料來源之書籍資料不含封面圖片
- **THEN** 系統得嘗試透過其他已核准來源以相同 ISBN 補足封面圖片

### Requirement: 以 ISBN 比對合併跨來源書籍資料
當同一本書之資料存在於多個已核准來源時，系統 SHALL 以 ISBN 作為判斷「是否為同一本書」並合併其資料的依據。

#### Scenario: 同一 ISBN 出現於多個來源
- **WHEN** 兩個已核准來源皆提供相同 ISBN 的書籍資料
- **THEN** 系統將兩者資料視為同一本書並合併呈現

#### Scenario: ISBN 僅出現於單一來源
- **WHEN** 某 ISBN 的書籍資料只存在於一個已核准來源
- **THEN** 系統以該來源提供的資料單獨呈現此書
